# QidianReader — Swift 原生起点阅读（登录 + 目录 + 阅读 + 本地缓存 + 进度恢复）

只做五件事：**登录**、**看目录**、**阅读**、**把下载过的章节留在本地**、**下次打开回到上次读到的地方**。

把章节链接粘进窗口就能读。左上角「功能」→「章节目录…」可以看当前书的完整目录，按卷分组、支持搜索，点任意一章直接开始读。正文不会像浏览器那样竖向滚动，而是按窗口大小自动分页，**左右各一页**：

- 点击左侧：上一页
- 点击中间或右侧：下一页
- 鼠标右键：上一页
- 键盘 `←` / `→`：上一页 / 下一页
- 本章最后一页再点下一页：自动进入下一章
- 本章第一页再点左侧：进入上一章，并落在最后一页

付费已购章节也能读——正文由官方 Fock 模块加密，客户端用离屏 `WKWebView` 复用官方解密。

读过的完整章节会按书名缓存到 `~/.qidian/<书名>/`；读完当前章后还会自动尝试缓存下一章。打开一本书后，还会在后台按「1 分钟 + 1 分钟 × 随机数」的间隔把整本书逐章补齐，已缓存的章节不会重复下载；下一章如果没购买（只能拿到试读片段），直接忽略，不会落盘。

退出后再次打开，会自动回到上次读到的章节和左右页位置。

> 接口细节（含完整端点清单）：[docs/API.md](docs/API.md)

## 运行

```bash
swift run QidianReader
# 或 open Package.swift，在 Xcode 里跑 QidianReader scheme
```

> 开发/调试时如果不想被 App 抢焦点，加 `--no-activate`：
>
> ```bash
> swift run QidianReader --no-activate
> ```
>
> 带这个 Flag 启动时，App 不会激活自己、也不会把窗口提到前台：窗口照常创建并可用，但会排在当前前台 App 的窗口后面，不会打断正在使用电脑的人。在 Xcode 里给 QidianReader scheme 的 Launch Arguments 加上 `--no-activate` 效果相同。

窗口左上角「功能」菜单集中了全部操作：打开章节链接、看章节目录、切换书籍、字号、主题、登录。正文区域只显示左右两页，不再保留顶部工具栏和底部状态栏。已登录时菜单里显示“已登录”；登录后会自动重拉当前章（试读 → 全文）。

> 本项目只提供 macOS 图形客户端，不再包含命令行工具。构建/测试命令：

```bash
swift build --disable-sandbox
swift test --disable-sandbox
```

> 如果窗口没有出现在前台：先 `killall QidianReader`，再重新运行。应用启动时会把自己的激活策略设为普通 App 并主动抢焦点；早期构建没有这一步，窗口会创建但藏在后台。

## 分页阅读

正文用 CoreText 按当前窗口大小、字号、行距排版，再切成左右两页显示：

- 左侧 1/3 区域：左键上一页；在第一章第一页时继续点，会进入上一章并落在最后一页。
- 中间 1/3、右侧 1/3 区域：左键下一页；在本章最后一页继续点，会加载下一章。
- 鼠标右键：任意位置上一页。
- 键盘 `←` / `→`：上一页 / 下一页；阅读区获得焦点时生效。
- 调整窗口大小或字号/行距后会自动重新分页，并尽量停留在当前阅读位置。
- 页码、翻页提示和下一章提示收在左上角「功能」菜单顶部；正文区域没有页脚。

## 章节目录与章节选择

左上角「功能」→「章节目录…」打开当前书的目录：

- 目录一次请求返回整本书，按卷分组；卷可以折叠/展开。
- 列表是**懒加载**的：`CatalogListLayout` 把目录算成固定行高的扁平行，界面只渲染「可视范围 + 上下各一屏缓冲区」的几十行，其余行用透明占位撑住（总高度不变，滚动条和滚动位置都稳定）。1373 章的目录也只实例化 40 个左右的视图，打开、滚动、搜索、折叠都不再卡顿。
- 滚动位置直接监听背后 `NSScrollView` 的 `clipView`（macOS 上滚动不会触发 SwiftUI 布局，`GeometryReader` + `PreferenceKey` 收不到回调），跳章/回顶部也直接改滚动位置，不依赖目标行已经渲染。
- 顶部显示卷数、章节数和作者；当前章节会高亮并标「在读」，打开时自动滚到那一章。
- 搜索框按章节名过滤（例如「冰封」「三百六十」）。
- 点任意一章会关闭目录并直接载入该章正文。
- 右上角刷新按钮强制重新拉目录；目录在本次运行内按书缓存，切换书籍再切回来不会重复请求。
- 目录 sheet 顶部可以在当前书和读过的书之间切换；也可以直接输入书籍 ID / 书籍页链接，读取任意一本书的目录（没有打开过书时同样可用）。
- 收费章节带锁图标，但能否读全文仍以账号权益为准（未购买时只返回试读片段）。

## 阅读进度与恢复

- 每本书保留最近一次阅读位置，记录在 `~/.qidian/progress.json`。
- 翻页、切换章节、调整窗口大小或字号/行距后都会更新进度。
- 启动时自动载入最近一本书的章节，并按正文锚点恢复到对应页码。
- 左上角「功能」→「切换书籍」列出所有读过的书（按最近阅读排序）；选中后载入该书上次读到的章节，并恢复到当时的页码。
- 同一本书只保留最新一条，最多保留 50 本书。
- 默认跟随 `QIDIAN_CACHE` 的根目录；也可用 `QIDIAN_PROGRESS` 单独指定进度文件。

## 本地缓存与整本后台下载

缓存根目录默认是 `~/.qidian`，可用环境变量 `QIDIAN_CACHE` 覆盖（进度文件也会跟着走）：

```
~/.qidian/
├── cookies.json
├── progress.json          # 最近阅读进度（每本书一条）
└── 牧者密续/
    ├── _book.json          # bookId / 书名 / 作者
    ├── 753919666.json      # 每章一个 JSON：标题、正文段落、上下章
    └── 801714441.json
```

规则：

- **按书名建目录**。书名里的 `/`、`:` 等文件系统非法字符会替换成 `_`；同名不同书追加 `-<bookId>`，不会串书。
- **只缓存完整章节**。试读片段、空正文不落盘；下次会重新向服务端请求。
- **读完当前章自动预取下一章**。后台串行执行，不阻塞当前阅读；快速翻页时只保留最新的预取请求。
- **打开一本书后开始整本后台下载**。按目录从当前章往后下，到结尾再绕回开头；每两章之间等待 `60 + 60 × 随机数` 秒（1–2 分钟），避免高频请求。
- **不重复下载**。启动队列时先扫磁盘，已缓存的章节直接跳过；等待期间用户自己读过的章节也会被跳过。切书或重启后重新打开同一本书，会从剩下的章节继续。
- **未购买/试读章节只探测一次**。接口返回试读或未购买时记入本次运行的跳过集合，不写文件、不反复请求；登录态变化后会清空该集合，重新给一次机会。
- **同一时间只下载一本书**。切换到另一本书会取消上一本的队列；功能菜单里可以暂停/继续，失败时也能重试。
- 再次打开同一章时优先读本地缓存，不重复解密、不重复下载。
- 同一章的并发请求（用户翻页 + 预取 + 整本下载）会合并成一个任务。
- 离屏 `WKWebView` 全局串行使用，避免后台下载和手动翻页同时 `load` 导致读到错误章节。
- 下载队列只覆盖打开这本书时的目录快照；连载新增的章节要重开 App（或刷新目录后切走再切回）才会进入队列。

## 只保留了五个能力

| 能力 | 实现 |
|---|---|
| 登录 | `WKWebView` 打开真实登录页，轮询到 `ywkey` 后保存 Cookie |
| 目录 | `mCategory` 一次取全书目录；功能菜单 sheet 按卷展示、搜索、跳章（懒加载，只渲染可视区 + 缓冲区） |
| 阅读 | `getMChapterInfo` 取章节 + 正文；密文回退 `WKWebView` 解密；CoreText 分页为左右双页 |
| 本地缓存 | 完整章节按书名写入 `~/.qidian/<书名>/<chapterId>.json`；读完自动预取下一章；打开书后按 1–2 分钟/章 后台补齐整本，跳过已缓存 |
| 阅读进度 | 每本书记录章节 + 正文锚点，启动时自动恢复上次页码 |

刻意没做：搜索、书籍详情、手工书架管理、评论、月票、云端阅读进度同步。

## 阅读链路

```
启动
  → 读 ~/.qidian/progress.json
       └─ 有记录：自动载入上次章节，并按正文锚点恢复页码
  → 无记录：显示欢迎页，等待从功能菜单打开链接
  → 功能菜单「章节目录」：GET /webcommon/book/mCategory
       └─ 按卷展示 → 搜索/选章 → ChapterRef
  → ChapterRef 解析出 bookId / chapterId
  → 查 ~/.qidian/<书名>/<chapterId>.json
       └─ 命中：直接分页渲染，并在后台预取下一章
  → 未命中：GET /webcommon/chapter/getMChapterInfo
       ├─ 免费章：<p> 明文 HTML → 段落
       └─ 已购章：Base64 密文 + fkp
              → 离屏 WKWebView 加载 /chapter/{bookId}/{chapterId}/
              → 官方 Fock 解密后读 span.content-text
  → 写入本地缓存（试读不写）
  → CoreText 按窗口大小分页 → SwiftUI 左右双页渲染
  → 翻页/换章写回 progress.json
  → 后台尝试缓存下一章；下一章未购买则忽略
  → 打开新书：按目录建整本下载队列（当前章 → 结尾 → 绕回开头）
       ├─ 跳过 ~/.qidian/<书名>/ 里已有的章节
       ├─ 每章之间等待 60 + 60 × 随机数 秒（1–2 分钟）
       └─ 试读/未购买写入本次运行的跳过集合，不落盘、不反复请求
```

## 为什么付费章节要用 WebKit

`fkp` 解码后是 `window.onkeyfocus("…", version)`，正文由 `window.Fock`（Emscripten 混淆的 WASM）解密，依赖账号 id + 每章密钥池。硬移植成本高、改版即失效；离屏 WebView 直接复用官方逻辑，约 2 秒/章，还顺带兼容字体混淆。

## 隐私与不入库内容

以下内容已由 `.gitignore` 排除，不会被提交：

- `~/.qidian/cookies.json`（登录票据，等同密码）
- `~/.qidian/<书名>/`（缓存正文，可能受版权保护）
- `~/.qidian/progress.json`（本地阅读进度）
- `.build/`、`.chrome/`、崩溃日志 `*.ips`

仓库里只有源码、测试与接口分析文档。

## 已知限制

- 只支持 `m.qidian.com`；`www.qidian.com` 有腾讯 WAF（202 + JS 挑战）。
- 未订阅章节只能读到试读片段，这是服务端按账号权益返回的，客户端不绕过。
- 缓存命中后不再校验服务端；章节正文更新（例如作者修文）不会自动同步，删掉对应 JSON 即可重新下载。
- 阅读进度按书保存；删掉 `~/.qidian/progress.json` 可清空恢复记录。
- 整本后台下载按 1–2 分钟/章 限速，上千章的书要跑十几到几十小时，期间需要保持 App 运行；关闭窗口会同时结束下载。
- 下载队列使用打开这本书时的目录快照；连载之后新增的章节，要重开 App（或在目录里刷新后切走再切回）才会进入队列。
- 整本下载只对**当前账号已购买**的章节有效；未购买章节会被跳过，登录/换号后会自动重算一次。
- 接口与密钥方案可能变化；解析失败时先看 [docs/API.md](docs/API.md)。
- 仅用于个人账号本地阅读；正文版权归作者与阅文所有，请勿分发。
